# Sticky List Headers

> Column Headings That Stay Where You Can See Them

Scroll a few hundred rows down a list and the column headings are long gone, leaving you guessing which column is the quantity and which is the price. This pins them in place.

## Features

- **Headings Stay Put** - The heading row stays at the top of the list while the rows scroll underneath it, so you always know which column you are reading.
- **Totals Stay Too** - The totals row is pinned to the bottom. On a long list that is every bit as useful as the headings, and it is the number people scroll to find.
- **Opaque By Design** - The pinned rows are given a solid background, so rows do not scroll visibly through them the way a naive sticky header lets them.
- **Pure Stylesheet** - No javascript and no patched views, so there is nothing to conflict with other modules or to break at the next upgrade.

## Getting Started

1. Install the module.
2. Reload the browser once so the assets rebuild.
3. Open a long list and scroll.

## Good To Know

- The module only adds a stylesheet, so removing it restores the default behaviour exactly.
- Works in every list view, including the one-to-many lists embedded in forms.
