PDF Watermark

Print DRAFT, PAID or anything else across a document

A quotation printed for discussion and a quotation that has been accepted look identical on paper. So do a paid invoice and an unpaid one. People find out which one they were holding after they have already acted on it. A rule says: for this kind of document, in this state, print this word behind the text.

Key Features

Behind the page, not in it

The watermark is drawn as an image tiled behind the page, so it cannot push content down, cannot break a table across a page boundary, and repeats down a long document.

Any document, any condition

Rules are written against a model and a domain, so DRAFT on unposted invoices, PAID on settled ones and CANCELLED on cancelled orders are three rules and no code.

Yours to look at

The word, its colour, how faint it is, the angle and the size are all on the rule, so a red DRAFT or a grey COPY needs no template editing.

The first rule that fits

Rules are ordered, so a narrow exception can sit above a broad rule rather than fighting it.

One place for every report

It hooks the layout that every printed document already passes through, so it covers the reports you have and the ones you add later.

Off until you say so

With no rules, every document prints exactly as it did before and carries no trace of the module at all.

Getting Started

  1. Install the module.
  2. Go to Settings > Technical > Watermark Rules.
  3. Pick the document type, write the condition, and type the word.
  4. Print one and check it: colour, angle and faintness are all on the same form.

Good To Know

  • A rule whose condition cannot be evaluated is skipped rather than allowed to stop the document printing.
  • The word is drawn into an image, so punctuation and angle brackets are safe.
  • Rules can be limited to one company, or left open to all of them.
