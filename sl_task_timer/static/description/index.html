Task Timer

Press Start, Press Stop, The Timesheet Writes Itself

Start a timer when you begin a task and stop it when you finish. The elapsed time becomes a timesheet entry, with no arithmetic and nothing to remember at the end of the day.

Key Features

One Timer At A Time

You cannot start a second timer while one is running. Two at once means at least one is recording hours nobody spent, and the entire value of a timesheet is that it is true.

It Tells You Where The Other One Is

Trying to start a second timer names the task the first is running on, so you can go and deal with it instead of hunting through your task list.

A Misclick Records Nothing

Stopping less than a minute after starting creates no timesheet entry at all. The timer really does stop and you are told why, so a stray click never pollutes a report.

Discard On Purpose

A separate Discard button throws the running time away deliberately, for when you realise you started the wrong task ten minutes ago.

Your Timer Is Yours

A timer belongs to the person who started it. Nobody else can stop or discard it, and two people can independently time the same shared task.

Visible While It Runs

A banner on the task form shows how long the current timer has been going, and Start and Stop are on the task list too, so you never have to open a record to start work.

Getting Started

  1. Install the module. It needs Project and Timesheets.
  2. Make sure your user is linked to an employee record.
  3. Open a task and press Start Timer.
  4. Press Stop and Record when you finish; the timesheet entry is created for you.

Good To Know

  • Time is rounded to two decimal hours on the timesheet entry.
  • A user without an employee record is told plainly rather than losing the time to a silent failure.
  • The timesheet entry is a normal one and can be edited or reassigned afterwards like any other.
