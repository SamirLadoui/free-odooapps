# Automatic Developer Mode

> Stop Turning It On Six Times A Day

If you work in developer mode you re-enable it after every logout, every cache clear and in every new browser. Set it once on your user and it is simply on whenever you log in.

## Features

- **It Sticks** - Developer mode is applied as your session is set up, so it survives logging out, clearing the cache and opening a brand new browser or an incognito window.
- **Assets Mode Too** - Choose plain developer mode or developer mode with assets, depending on whether you are reading data or debugging the front end.
- **Administrators Only** - Only Settings administrators can be put into automatic developer mode. It exposes technical menus and internal fields, which is not somewhere to drop a user who did not ask for it.
- **Re-checked On Every Write** - An administrator who later loses those rights cannot keep the setting; the check runs again whenever it is saved.
- **Set It Yourself** - The option lives on your own preferences, so a developer can enable it without going through anybody else.

## Getting Started

1. Install the module.
2. Open your own user record, or Settings > Users, and go to Preferences.
3. Set Automatic Developer Mode to Developer mode, or Developer mode with assets.
4. Reload. It stays on from now on.

## Good To Know

- Only Settings administrators can have this enabled; anyone else is refused with a message.
- Turning the setting off returns you to Odoo's normal behaviour immediately.
- It does not grant any right the user did not already have; it only turns on a mode they could already enable by hand.
