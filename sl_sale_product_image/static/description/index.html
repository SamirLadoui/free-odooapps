Product Images On Quotations

Let The Customer See What They Are Buying

Print each product's picture beside its line on quotations and sale orders. Off by default, because installing a module should not silently change the look of every quotation you send.

Key Features

Pictures Where They Help

The product image prints beside its description, so a customer reading a quotation sees the item rather than a product code.

No Empty Boxes

A product with no image is simply skipped. No broken image icons and no gap where a picture should have been.

It Does Not Break Your Layout

The image goes above the description rather than in a new column. Adding a column reflows every other one and breaks the layouts other modules have already adjusted.

A Size That Makes Sense

Choose the height, capped between 16 and 200 pixels. Larger and a single line fills a page; smaller and it is a smudge.

Off Until You Say So

Nothing changes when you install it. Turning it on is a deliberate choice made in Settings.

Per Company

Each company chooses for itself, so a multi-company database can print differently for each without extra work.

Getting Started

  1. Install the module and open Settings > Sales.
  2. Under Quotations and Orders, tick Product Images On Quotations.
  3. Set the image height if the default does not suit you.
  4. Print a quotation to check it.

Good To Know

  • Only products that actually have an image get one printed.
  • The module changes the printed document only; the order form is untouched.
  • Image size is limited to a sensible range so a quotation cannot accidentally become one line per page.
