Employee Documents

Nothing Lapses Unnoticed

Passports, visas, work permits, licences and contracts, with the dates that matter and a reminder before any of them expire. The list opens on exactly the documents that need attention today.

Key Features

Status Works Itself Out

Every document knows whether it is valid, expiring soon, expired, or simply has no expiry date. You never maintain a status by hand.

A Window Per Document Type

Expiring soon means something different for a passport than for a parking permit. Each type carries its own warning window, and its own answer to whether it expires at all.

Someone Actually Gets Told

A daily check raises an activity for whoever is responsible, falling back to the employee's manager, and notes it in the document's own log. No silent spreadsheet nobody opens.

Chased Once, Not Ten Times

A document is reminded about at most once a day, so a permit that has been expired for a month does not fill anyone's inbox.

Opens On What Matters

The default view is filtered to expiring and expired documents, so the first thing you see is the work, not the archive.

Dates That Make Sense

A document that expires before it was issued is refused outright, so a typo is caught at entry rather than skewing your reminders later.

Getting Started

  1. Install the module and open Employees > Configuration > Document Types.
  2. Create your types, each with its own warning window.
  3. Add documents from Employees > Documents, or from the Documents button on any employee.
  4. Enable the Employee Documents: Expiry Reminders scheduled action. It ships disabled so nothing fires until your data is loaded.

Good To Know

  • Reminders go to the document's responsible user, or the employee's manager when none is set.
  • A document type can be marked as never expiring, for things like diplomas.
  • Access follows Odoo's own HR groups: officers manage documents, managers manage the types.
