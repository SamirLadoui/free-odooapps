# Export Product Stock to Excel

> On Hand, Reserved And Forecasted Stock, Filtered, In One .xlsx

A single wizard that turns your inventory into a spreadsheet you can actually work with. Pick a shape, pick your filters, press Export, and get a file with a frozen header row and an autofilter already applied.

## Features

- **Two Shapes** - One row per product gives you a stock summary. One row per product and location breaks the same quantities down by where the goods physically are.
- **Down To The Lot** - In per-location mode you can break the export down further by lot or serial number, which is what you need for a traceable stock count.
- **Filters That Combine** - Warehouses, internal locations, product categories or an explicit product list. Every filter narrows the selection, so naming a product outside your chosen category will not pull it back in.
- **The Columns You Expect** - Reference, product, category, unit of measure, on hand, reserved, available and forecasted, plus location and lot where they apply.
- **Optional Valuation** - Add unit cost and stock value columns when you need the numbers, leave them off when you are just counting boxes.
- **Ready To Use On Open** - The header row is frozen and an autofilter is already applied, so you can sort and pivot the moment the file opens instead of setting it up yourself.

## Getting Started

1. Install the module.
2. Go to Inventory > Reporting > Export Stock to Excel.
3. Choose the shape, set your filters, and press Export. The file downloads immediately.

## Good To Know

- Requires the xlsxwriter Python package, which ships with a standard Odoo install.
- Access is limited to the Inventory user group.
- Ticking Include Products With No Stock turns the export into a full catalogue listing rather than a stock listing.
