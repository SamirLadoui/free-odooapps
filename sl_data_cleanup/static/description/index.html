Remove Data

Clear A Database Before You Go Live

Clear the orders, invoices, transfers and test records out of a database before you start using it for real, without rebuilding it from scratch.

Key Features

Count Before You Cut

Count First tells you exactly how many records each switch would remove, before anything is touched.

Hard To Fire By Accident

You have to type the database name in full to confirm. A tick box is too easy to click for something that cannot be undone.

Administrators Only

Settings administrators see the menu and the wizard. Nobody else can reach it, from the interface or otherwise.

It Keeps What The Database Needs

The contacts of your companies and of every user survive. Removing those breaks a database rather than cleaning it.

Works On Any Database

Categories belonging to modules you have not installed are skipped quietly, so the same wizard works on a small database and a full one.

Documents That Fight Back

Posted entries and done transfers are set to draft or cancelled first, so a removal does not fail halfway through.

Getting Started

  1. Take a backup. This cannot be undone.
  2. Install the module and open Settings > Remove Data.
  3. Tick the categories you want cleared and press Count First.
  4. Type the database name and press Remove Data.

Good To Know

  • Every removal is written to the server log with the user who ran it.
  • Intended for clearing a database before go-live, not for routine housekeeping.
  • Contacts attached to a user or to one of your companies are always kept.
