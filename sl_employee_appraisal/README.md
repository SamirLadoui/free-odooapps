# Employee Appraisal

> A Score That Reflects What You Actually Care About

Run periodic appraisals against criteria you define, weighted so the things that matter most count for most. No spreadsheets, no arithmetic, and no appraisal that quietly scores half the questions.

## Features

- **Weighted, Not Averaged** - Every criterion carries a weight. If quality matters three times as much as punctuality, say so once and every appraisal from then on reflects it.
- **Half Finished Is Not Half Bad** - Criteria that have not been rated yet are ignored rather than counted as zero, so an appraisal in progress never looks like a poor one.
- **Cannot Be Completed Early** - An appraisal refuses to close while any criterion is still unrated, so a final score is always based on the whole assessment.
- **Criteria Load Themselves** - Pressing Start pulls in every active criterion at its own weight, ready to rate. Add a criterion later and Load Criteria brings in just the new ones.
- **One Per Employee Per Period** - Overlapping appraisals for the same person are refused, because two competing reviews of the same six months make the history meaningless. Cancelling one frees the period again.
- **Room For The Exception** - A per-line weight override for the review where one thing genuinely mattered more, plus strengths, areas to improve, and the employee's own comment.

## Getting Started

1. Install the module and open Employees > Configuration > Appraisal Categories.
2. Add your categories, then the criteria under them, each with a weight.
3. Go to Employees > Appraisals, create one for an employee and a period, and press Start.
4. Rate every criterion, then press Complete.

## Good To Know

- Scores are out of five and also shown as a percentage.
- The appraising manager defaults to the employee's own manager and can be changed.
- Access follows Odoo's own HR groups: officers run appraisals, managers define the criteria.
