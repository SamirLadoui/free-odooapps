# School Attendance

> Mark The Exceptions, Not The Whole Class

A register per class per day, and an attendance rate you can defend. Everyone loads in present, so the teacher marks the handful who are not, rather than thirty children one at a time.

## Features

- **A Few Clicks, Not Thirty** - Load Students puts every enrolled student on the register marked present. In a normal class most people are there, so only the exceptions need touching.
- **Late Is Not Absent** - Four states: present, late, absent and excused. Late counts as present for the rate, because the child was in the room.
- **One Register Per Day** - Two registers for one class on one day means one of them is wrong and no report can tell you which. The second is refused.
- **Nobody On The Wrong List** - A student from another class cannot be added, nobody can appear twice, and a register dated outside its academic year is refused.
- **Enrolment, Not Application** - Only enrolled students load onto a register. Someone who has applied but not started is not marked absent for lessons they were never expected at.
- **Rates That Only Count Facts** - Every student carries an attendance rate over confirmed registers only. A draft register is not yet a fact about anybody, so it does not move anyone's percentage.

## Getting Started

1. Install the module. It extends the School app.
2. Open School > Attendance and create a register for a class and a date.
3. Press Load Students, mark the absences, and press Confirm.
4. Each student's rate and history appear on their own Attendance tab.

## Good To Know

- Excused absences count against the attendance rate but are recorded separately, so you can tell an authorised absence from a truancy.
- The class teacher is filled in automatically as the person taking the register.
- A confirmed register can be reset to draft if something needs correcting.
