# Full Width Form Sheets

> Use The Whole Window, Not A Narrow Column

Odoo caps the width of a form sheet. On a wide monitor, and on forms with many columns, that cap wastes half the screen and forces horizontal scrolling inside one-to-many lists. This lifts it.

## Features

- **Forms Fill The Window** - Form views use the full width available instead of a fixed centre column, so wide one-to-many lists stop scrolling sideways inside a narrow sheet.
- **Settings Left Alone** - Configuration pages are laid out in fixed columns on purpose. Stretching them makes them harder to read, so they keep their own width.
- **Nothing To Configure** - No settings, no per-user options, no menu. Install it and forms are wider; uninstall it and they are not.
- **Pure Stylesheet** - No javascript, no patched views and no model changes, so there is nothing to conflict with other modules or to break at the next upgrade.

## Getting Started

1. Install the module.
2. Reload the browser once so the assets rebuild.
3. Open any form view.

## Good To Know

- Configuration and settings pages deliberately keep their original width.
- The module only adds a stylesheet, so removing it restores the default layout exactly.
