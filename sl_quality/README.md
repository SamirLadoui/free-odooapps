# Quality Management

> Something Went Wrong. Why, And What Are We Doing About It?

Non-conformities, root cause analysis and corrective actions, with a workflow that cannot be short-circuited. Closing a non-conformity is a claim that it will not happen again, so the module makes you earn it.

## Features

- **No Actions Without A Cause** - You cannot raise actions until a root cause is recorded. An action without a cause is a guess, and guesses do not stop problems recurring.
- **No Closing With Work Outstanding** - A non-conformity cannot be closed while any action is still open, or before a root cause is written down. Cancelled actions do not block it, because deciding not to do something is a decision.
- **Corrective And Preventive** - Corrective fixes what went wrong. Preventive stops it happening somewhere it has not yet. Each action has an owner and a deadline.
- **Overdue Actions Are Loud** - Past-deadline actions turn red, are counted on the non-conformity, get a banner on its form, and can be filtered on. Finishing late clears the flag, because finishing late is still finishing.
- **Containment Kept Separate** - What you did in the first hour to limit the damage is recorded separately from what you concluded in the first week. They are different things and conflating them loses both.
- **Typos Caught Early** - An action due before the non-conformity was even reported is refused, because that is always a mistake rather than an intention.

## Getting Started

1. Install the module and open the Quality app.
2. Record a non-conformity: what happened, where it came from, how severe.
3. Press Start Analysis, write the root cause and any immediate containment.
4. Add corrective and preventive actions with owners and deadlines, then Raise Actions.
5. Once every action is done or cancelled, a Quality Manager can Close it.

## Good To Know

- Two access levels: users report non-conformities and work on actions, managers close and reopen them.
- The list opens filtered to what is still open, so the first thing you see is the work.
- Origin and severity are both filterable and groupable, for the reporting an auditor will ask for.
