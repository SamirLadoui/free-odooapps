# Sale Rental

> Hire Things Out On The Sale Orders You Already Use

Tick a sale order line as a rental, give it a hire date and a return date, and it prices itself from the product's daily, weekly and monthly rates. Confirming the order checks you actually have one free.

## Features

- **Pricing A Customer Would Recognise** - A hire uses the largest rates first, so 38 days is a month plus a week plus a day rather than 38 separate days. A longer hire is never dearer than a shorter one, and there is a test walking every duration from one day to two months to prove it.
- **Missing Rates Are Skipped, Not Free** - If you only set a weekly rate, a nine-day hire still costs more than a week. Nothing goes out for nothing because a rate happened to be blank.
- **Availability That Holds** - Each product records how many units you own. Confirming an order checks the window against every other confirmed hire and refuses it once they are all out, naming how many are free.
- **Quotations Hold Nothing** - Only confirmed orders reserve stock. If drafts blocked units, one abandoned quotation would take an item off the market forever.
- **Both Ends Inclusive** - Out and back on the same day is one day's hire, not zero. That is how the customer counts it, so it is how the module counts it.
- **On Your Existing Orders** - No separate rental app to learn. Rental lines sit alongside ordinary sale lines on the same order, so one document can carry both.

## Getting Started

1. Install the module. It needs Sales.
2. Open a product, tick Can Be Rented, and set the units you own and your rates.
3. On a sale order, tick Rental on a line and set the hire and return dates.
4. Confirm the order; availability is checked at that point.

## Good To Know

- A product marked rentable with no rate at all is refused, since it would go out for nothing.
- A rental line needs both dates, and a return date cannot precede the collection date.
- Availability counts confirmed and done orders only.
