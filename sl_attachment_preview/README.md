# Attachment Preview

> See What Is In A File Without Downloading It First

Adds a Preview button to every attachment in Odoo. Images, PDFs, text files, video and audio open in a page that actually shows them, instead of landing in your downloads folder so you can find out what they were.

## Features

- **Text Files, Finally Readable** - Browsers download .csv, .log, .json, .xml and .sql rather than showing them. This module renders them in a scrollable pane, which is the case where a preview saves the most time.
- **Images And PDFs Inline** - Images are fitted to the window on a neutral background, and PDFs render inline at page width, so you can check a document without leaving Odoo.
- **Video And Audio** - Attached recordings and clips play in the browser's own player, with no plugin and no download.
- **An Honest Fallback** - A file type that cannot be shown gets a clear card explaining that and a download button, instead of a broken embed or a blank page.
- **Page Through A Record** - Previous and next arrows walk the other attachments of the same record, so you can review everything attached to an order or an invoice in a few clicks.
- **Safe With Big Files** - Text previews stop at 200 KB with a note saying so, so opening a large log file does not hang the browser.

## Getting Started

1. Install the module.
2. Open any attachment, from Settings > Technical > Attachments or from a record's attachment list.
3. Press Preview. The file opens in a new tab.

## Good To Know

- The preview page reads the attachment as the logged-in user, with no elevation of privilege. Normal Odoo attachment access rules decide what each user can open.
- Anonymous visitors are sent to the login page, never to a file.
- The attachment list gains a Preview column, so you can see at a glance which files can be displayed.
